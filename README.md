## how i use this
 
i try to solve first, look at hints only if i've been stuck for a while, and write the solution in a way that i'd understand if i came back to it six months later. the comments aren't for the grader — they're for future me.
 
if a problem has multiple approaches (brute force → optimized, or two different algorithms), i'll usually keep both so i can see the difference.
